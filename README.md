# Employee Attrition Analysis

## Project Overview

This project focuses on analyzing employee attrition using Python and data analytics techniques. The objective is to identify patterns and factors associated with employees leaving an organization by examining employee demographics, job roles, compensation, performance, engagement, and other HR-related attributes.

## Project Objectives

- Understand employee attrition patterns.
- Explore workforce demographics and employment characteristics.
- Analyze relationships between employee attributes and attrition.
- Identify factors that may be associated with employee turnover.
- Develop data-driven insights and recommendations for employee retention.

## Dataset

The project uses a synthetic HR Analytics dataset containing **10,000 employee records and 95 columns**.

**Original Dataset Repository:**  
https://github.com/Ayeohkayy/synthetic-hr-analytics-database

The original dataset contains multiple interconnected HR tables, which were consolidated into an employee-level dataset for analysis.
